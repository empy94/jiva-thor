# Pistes pour le second écran

Ces idées sont des propositions à discuter avec le développeur du jeu ; elles ne décrivent pas des fonctions déjà disponibles.

1. **Favoris vraiment autonomes.** Exposer les sorts appris et les objets utilisables avec leurs identifiants et icônes, puis une action explicite de sélection. Cela éviterait de dépendre d’une place dans la barre du jeu et de devoir ouvrir temporairement le livre ou le sac.
2. **Aide au combat fiable.** Fournir les PA, PM, portée, disponibilité et état du tour, puis éventuellement les cases accessibles et les cibles autorisées. Le second écran pourrait expliquer pourquoi une action est indisponible, sans deviner à partir d’une image.
3. **Carte plus précise.** Si des tuiles plus détaillées existent, permettre leur chargement progressif et proposer des repères interactifs issus du jeu.
4. **Chat confortable.** Fournir les canaux, couleurs et historique via une interface stable pour conserver la présentation du jeu et filtrer sans manipuler son interface principale.
5. **Informations à la demande.** Afficher énergie, effets et autres données seulement si le jeu peut les transmettre de façon fiable ; éviter les chiffres périmés et les panneaux qu’il faut ouvrir manuellement.

Une interface locale documentée, limitée aux informations nécessaires et sans identifiants dans les journaux ou le dépôt, faciliterait ces évolutions. Les actions devraient rester déclenchées par le joueur.
